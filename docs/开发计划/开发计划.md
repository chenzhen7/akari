## 技术风险速查

| 风险 | 影响阶段 | 处理建议 |
|------|---------|---------|
| `node-pty` Windows 需 VC++ Build Tools | 二/三 | WSL2 开发；降级用 `child_process.spawn` |
| xterm.js + React 18 Strict Mode 双重挂载 | 三 | `useRef` 保护初始化，`useEffect` 返回 `dispose()` |
| Monaco Editor 包体积 ~2MB | 三 | 动态 `import()` 懒加载 |
| 审批不可绕过 | 四/五 | Agent 适配器禁止自动回复，必须经 `handleApproval` |
