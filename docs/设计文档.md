## 一、产品定位与核心理念

```
核心理念：「指挥中心」模式
- 你是指挥官，Agent 是并行执行的士兵
- 无限画布 = 战场全局视图
- 看板 = 任务状态流转
- Tab = 快速聚焦单个战场
- Worktree = 物理隔离的并行战线
```

## 三、关键交互流程

```
用户创建任务
     │
     ▼
创建 Git Worktree ──→ 独立分支隔离
     │
     ▼
启动 Agent 进程 ──→ 注入 Checkpoint 协议
     │
     ▼
实时监控输出 ──→ 推送到画布卡片
     │
  ┌──┴──┐
  │检测到│
  │审批点│
  └──┬──┘
     │
     ▼
暂停 Agent ──→ 推送审批请求到前端
     │
     ▼
用户 Review Diff ──→ 批准/拒绝
     │
  ┌──┴──┐
  │批准  │
  └──┬──┘
     │
     ▼
恢复 Agent 继续执行
     │
     ▼
完成 ──→ Squash Merge 到主分支 ──→ 清理 Worktree
```
